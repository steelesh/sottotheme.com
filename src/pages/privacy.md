# Privacy

Last updated 13 November 2026.

This site collects nothing about you.

## What the site does not do

- It sets no cookies and stores nothing in your browser.
- It runs no analytics, ads or tracking scripts.
- It loads nothing from other companies. Fonts, images and scripts all come from this domain.
- It has no forms, accounts or newsletter.

## What the host records

The site is served by GitHub Pages. GitHub logs the IP address of every visitor for security purposes. That record is kept by GitHub under the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement), and this site has no access to it.

## Copy buttons

The copy buttons on the install tab write the command to your clipboard. Nothing is read from your clipboard and nothing is sent anywhere.

## Links that leave the site

Links to GitHub, the Visual Studio Marketplace and the JetBrains Marketplace take you to those sites, which have their own privacy policies.
