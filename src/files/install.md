## VS Code

```sh
code --install-extension steelesh.sotto
```

Or find Sotto in the [Marketplace][1]. Cursor, Windsurf and VSCodium install it from [Open VSX][4].

## JetBrains

`Settings > Plugins > Marketplace`

Search for Sotto, or open it in the [Marketplace][3]. Add [Sotto Icons][5] for file icons.

## Neovim

```lua
-- lazy.nvim
{ "steelesh/sotto" }
vim.cmd.colorscheme("sotto")
```

## Everything else

Ghostty, tmux, fzf, bat, delta, lazygit, yazi and more. [Themes on GitHub][2]
